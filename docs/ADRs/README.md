# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for the actBI monorepo.

## What are ADRs?

ADRs are lightweight documents that capture important architectural decisions and their rationale. Each ADR describes:

- **Context**: The situation and constraints
- **Decision**: What was decided
- **Consequences**: The implications of the decision

## ADR Template

When creating a new ADR, use this format:

```markdown
# NNN: Title

**Status**: Proposed | Accepted | Deprecated | Superseded by NNN

**Date**: YYYY-MM-DD

## Context

What is the issue that we're seeing that is motivating this decision?

## Decision

What is the change that we're proposing and/or doing?

## Consequences

What becomes easier or more difficult because of this change?
```
